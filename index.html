            🧹
            처음 상태로 초기화이 기기의 기록을 지우고 기본값으로 돌아가요
            ☁️ 실시간 연동같은 방 코드를 넣은 가족 기기끼리 채팅 · 퀘스트 · 일정이 바로 맞춰져요
            이렇게 쓰면 돼요
            1. 가족끼리 정한 비밀 코드를 넣고 저장하면 바로 연결돼요 (주소는 이미 채워져 있어요)
            2. 가족 기기에서도 같은 코드를 넣으면 채팅 · 퀘스트 · 일정이 함께 맞춰져요
            3. 코드를 바꾸면 그 코드의 방으로 옮겨가고, 끄면 이 기기에만 저장되고 인터넷 없이도 열려요 (아래 실시간 해제)

            비밀 코드를 아는 사람은 함께 볼 수 있어요. 짐작하기 어렵게 가족만 아는 숫자를 붙여 보세요 (예: 우리집-7391).
            연결이 안 되면 console.firebase.google.com → Realtime Database → 규칙(Rules)에서 읽기·쓰기를 열어 둬요 — "read": true, "write": true

            이 기기에만 저장되는 로컬 모드예요

            📲 휴대폰 푸시 알림앱을 닫아 두어도 가족 메시지가 알림으로 와요 · 홈 화면에 추가하면 가장 잘 돼요

            이 기기에서는 아직 푸시 알림을 켜지 않았어요

            이렇게 하면 돼요
            1. 휴대폰에서 이 화면을 열고 홈 화면에 추가해 주세요 (안드로이드 Chrome · 아이폰 Safari 공유 → 홈 화면에 추가)
            2. 홈 화면 아이콘으로 열어 알림 켜기를 누르고, 알림을 허용해 주세요
            3. 가족 기기마다 한 번씩 켜 두면 서로의 메시지가 알림으로 와요

            푸시 서버 주소는 이 방을 쓰는 가족 기기끼리 함께 저장돼요. 비워 두면 휴대폰 알림 없이 화면 안 알림만 써요.
            아이폰은 iOS 16.4부터 홈 화면에 추가한 앱에서만 푸시가 와요.
